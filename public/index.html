        When you enter names only, students will be shuffled and shared as evenly as possible across these classes. You can also provide a class beside each name.

        Set a preferred size on each class chip; students are assigned to meet those targets first, then remaining students are balanced.

        Save and reuse a roster

        Saved rosters sync to your school account when signed in; local mode keeps them in this browser. Use Delete to remove a saved list.

        Import a list or a pictureCSV, text, Word (.docx), PDF, or a clear image of a class list.

        ✳Format: one student per line, or student name then class separated by a comma or tab. A header row is okay.
        CSV columns: student name, class (optional), balance group (optional). Check imported names and groups before shuffling.

        Use only school-approved grouping information. The value is used to spread matching groups evenly.
